# Golden-violet Japanese editorial redesign

## Direction
Transform the existing portfolio into a curated cosmic magazine: ink-black space, antique gold and luminous amber drawn from the uploaded nebula, with controlled violet retained around the astronaut so the existing hero still feels cohesive. Use Cormorant Garamond for expressive editorial headings and Karla for crisp supporting copy.

## Build
- Preserve the faceless astronaut hero, giant ABHINAV BYJU identity, all current portfolio content, links, 3D cards, and interactive library.
- Add the uploaded golden nebula as a layered atmospheric material rather than a literal full-page wallpaper.
- Recompose section introductions with Japanese art-book hierarchy: oversized serif titles, small indexed labels, fine gold rules, vertical Japanese accents, and alternating magazine rhythm.
- Retheme surfaces, borders, glows, stars, shelves, card glare, and footer using semantic black/gold/violet tokens.
- Add restrained motion: masked text reveals, slow nebula drift, fine particle movement, and light sweeps, while honoring reduced motion and keeping mobile effects simplified.
- Update font loading in the document head and keep route metadata intact.

## Verification
- Check the live page at desktop and mobile widths for overlap, readability, image framing, animation, and layout stability.
- Confirm the page has no runtime console errors and the latest build succeeds.
